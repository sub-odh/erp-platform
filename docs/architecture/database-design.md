# ERP Database Design

## Source of truth

This database is designed as a fresh PostgreSQL schema.

The architecture blueprint defines:

- PostgreSQL 16
- tenant isolation with Row-Level Security
- module-prefixed table names
- modular monolith boundaries
- Drizzle ORM migrations
- shared platform services

The legacy MySQL dump is used only to identify useful business concepts and workflows. No legacy records are imported.

## Global conventions

### Identifiers

- Primary keys use UUID.
- Foreign keys use UUID.
- IDs are generated by PostgreSQL.
- No legacy numeric IDs are retained.

### Tenant ownership

Every tenant-owned table includes:

```sql
tenant_id uuid not null
```
